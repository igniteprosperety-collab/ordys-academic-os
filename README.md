# Ordys Academy

Crie o conceito completo de um aplicativo premium de produtividade acadêmica chamado ORDYS, desenvolvido para estudantes do ensino médio e ensino superior.



O Ordys não é apenas um calendário escolar e não é apenas um to-do list.



É um sistema operacional pessoal para a vida acadêmica do estudante, reunindo organização, aprendizagem, produtividade e acompanhamento de desempenho em uma única experiência.



Posicionamento:



ORDYS

Disciplina • Aprendizagem • Praticidade



A proposta do produto é fazer o aluno sentir que toda a sua vida acadêmica está organizada em um único lugar.



O sistema deve ajudar o estudante a responder rapidamente:



O que tenho hoje?

O que preciso fazer?

Quando tenho prova?

O que preciso estudar?

Como estou indo?

Estou atrasado em alguma coisa?

Quanto estou evoluindo?



O produto deve atender estudantes de aproximadamente 14 anos até universitários adultos.



A interface, entretanto, nunca deve parecer infantil.



Deve parecer uma empresa de tecnologia premium, moderna, madura e confiável.



---



DIREÇÃO DE PRODUTO



O Ordys deve ser apresentado como um produto real de tecnologia, não como uma landing page ou um mockup superficial.



Imagine uma combinação de:



Apple + Notion + Linear + calendário inteligente + sistema acadêmico moderno.



Porém, não copiar nenhum desses produtos.



O Ordys precisa possuir identidade própria.



A complexidade funcional deve existir na arquitetura do produto, enquanto a interface permanece extremamente simples.



O estudante não deve sentir que está utilizando um software corporativo complexo.
